> I put "Do Not Disturb" on my calendar and my manager booked a meeting called "Quick chat about your Do Not Disturb".

A one-line joke about office life, written for the make.fun bounty "Make the AI Judge Laugh: Office Jokes". The joke is about a calendar "Do Not Disturb" that gets answered with a meeting about the Do Not Disturb itself — the one signal meant to keep meetings away becomes the reason for another meeting.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

`main.ts` (Node 22, `node:fs` only, no network) writes the line as a single line to `/output/entry.txt`. Deterministic — every run produces the same bytes. The program self-checks the bounty gate: one line, 1 to 199 characters (the line is 116 characters).
